# Switch

An on/off toggle for settings, 44 × 26 px, `seal` when on.

**Markup:** `<button class="hb-switch" role="switch" aria-checked="false" aria-label="…">`. Put it at the end of a row whose text names the setting; the label states what "on" does ("Dim the screen while locked"), never a question.

**States:** off = `surface-sunken` track, `line-strong` border, `ink-muted` knob. On = `seal` track, `on-seal` knob. Focus = `focus-ring`.

**Settings this product uses:** Dim the screen while locked · Show keys I press while locked · Start Hushboard at login · Play a sound when the lock ends.
