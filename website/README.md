# Hushboard website

The landing page for Hushboard, built with Next.js and Tailwind CSS.

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

Colours and fonts follow the app's design system in `../design-system/project/tokens.json`.
The logo lives in `public/brand.svg` and doubles as the favicon (`src/app/icon.svg`).
